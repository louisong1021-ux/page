KALI USB SETUP

复制命令，完成账号配置

请在 SwiftiGo 笔记本上打开 管理员 PowerShell，复制并执行下面的命令。执行时会提示输入临时登录密码（输入过程不显示字符）。

PowerShell 命令
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\Users\louis\Downloads\KaliUSB\finish-kali-account.ps1"
  1. 在笔记本上右键 PowerShell，选择“以管理员身份运行”。
  2. 粘贴命令并按 Enter。
  3. 按提示输入保存在你私人 Notion 中的临时密码。
  4. 看到 LOGIN_ACCOUNT_READY=YES 后回到聊天继续。
本页面仅用于复制命令，不会远程执行、删除磁盘文件或保存密码。临时密码不在公开 GitHub 页面中。

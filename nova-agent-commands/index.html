SWIFTYGO 部署命令

在笔记本电脑打开本页，逐段点击“复制命令”，粘贴到 PowerShell。当前只建议执行第一项检查；其余命令须等待正式更新包发布。

公开命令参考页 · 不包含密码、Token 或设备密钥
重要：本页针对 SWIFTYGO 笔记本，不是 XPS 台式机。日志轮转功能仍在 Nova-MCP PR #5 审查中，尚无正式更新包或发布用 SHA-256。目前不要执行 Verify / Apply / Accept。
01 · 现在可以执行

检查 SWIFTYGO 当前状态

只读操作。建议先在笔记本的 PowerShell 运行，确认自己打开的是正确电脑。

$root = "C:\ProgramData\NovaAgent-BootPilot"
Write-Host "当前电脑: $env:COMPUTERNAME"
Write-Host "更新程序存在: " (Test-Path "$root\private\Update-PyAgentBoot.ps1")
Write-Host "正式更新包存在: " (Test-Path "$root\incoming\nova-boot-logging.zip")
Get-ScheduledTask -TaskName "Nova-Windows-Agent-Boot" |
  Select-Object TaskName, State
Get-ScheduledTask -TaskName "Nova-WSL-Kali-KeepAlive" |
  Select-Object TaskName, State
02 · 正式包发布后

验证更新包（Verify）

需要 GitHub PR #5 审查通过、正式 ZIP 已放进 incoming，并且取得发布公告提供的独立 SHA-256。

$ErrorActionPreference = "Stop"
if ($env:COMPUTERNAME -ne "SWIFTYGO") {
  throw "这组命令只用于 SWIFTYGO 笔记本，请勿在 XPS 上执行。"
}
$root = "C:\ProgramData\NovaAgent-BootPilot"
$tool = "$root\private\Update-PyAgentBoot.ps1"
$zip = "$root\incoming\nova-boot-logging.zip"
$sha = "请粘贴正式发布公告中的64位SHA256"
if (-not (Test-Path -LiteralPath $tool)) { throw "更新程序不存在" }
if (-not (Test-Path -LiteralPath $zip)) { throw "正式更新包还未发布，停止操作" }
if ($sha -notmatch '^[0-9a-fA-F]{64}$') { throw "请先填写真实 SHA256" }
if ((Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash -ne $sha) {
  throw "更新包与发布时的 SHA256 不一致"
}
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File $tool -Action Verify -InstallRoot $root -BundleFile $zip -BundleSha256 $sha
if ($LASTEXITCODE -ne 0) { throw "校验失败，禁止更新" }
03 · 正式包发布后

应用更新（Apply）

会短暂停止 Nova Windows Agent，并保留回退版本。通过 Verify 才能执行。

$ErrorActionPreference = "Stop"
if ($env:COMPUTERNAME -ne "SWIFTYGO") {
  throw "这组命令只用于 SWIFTYGO 笔记本，请勿在 XPS 上执行。"
}
$root = "C:\ProgramData\NovaAgent-BootPilot"
$tool = "$root\private\Update-PyAgentBoot.ps1"
$zip = "$root\incoming\nova-boot-logging.zip"
$sha = "请粘贴正式发布公告中的64位SHA256"
if (-not (Test-Path -LiteralPath $tool)) { throw "更新程序不存在" }
if (-not (Test-Path -LiteralPath $zip)) { throw "正式更新包还未发布，停止操作" }
if ($sha -notmatch '^[0-9a-fA-F]{64}$') { throw "请先填写真实 SHA256" }
if ((Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash -ne $sha) {
  throw "更新包与发布时的 SHA256 不一致"
}
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File $tool -Action Verify -InstallRoot $root -BundleFile $zip -BundleSha256 $sha
if ($LASTEXITCODE -ne 0) { throw "校验失败，禁止更新" }
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File $tool -Action Apply -InstallRoot $root -BundleFile $zip -BundleSha256 $sha -Confirmed
if ($LASTEXITCODE -ne 0) { throw "更新失败，请检查并回滚" }
04 · 远程验收通过后

确认更新（Accept）

必须先通过 Nova MCP 在 SWIFTYGO-BOOT 上实际执行 Windows 命令，再确认。

$ErrorActionPreference = "Stop"
if ($env:COMPUTERNAME -ne "SWIFTYGO") { throw "只允许在 SWIFTYGO 上执行" }
$root = "C:\ProgramData\NovaAgent-BootPilot"
$tool = "$root\private\Update-PyAgentBoot.ps1"
# 先从 ChatGPT 的 Nova MCP 对 SWIFTYGO-BOOT 执行实际命令，确认新版本正常。
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File $tool -Action Accept -InstallRoot $root -Confirmed
05 · 如验收失败

恢复原版（Rollback）

更新后有异常时使用。它会恢复更新程序保存的旧版本。

$ErrorActionPreference = "Stop"
if ($env:COMPUTERNAME -ne "SWIFTYGO") { throw "只允许在 SWIFTYGO 上执行" }
$root = "C:\ProgramData\NovaAgent-BootPilot"
$tool = "$root\private\Update-PyAgentBoot.ps1"
powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File $tool -Action Rollback -InstallRoot $root -Confirmed
本页面只是命令参考，不会自行执行 PowerShell，不会修改 Agent。更新前请保存发布包的独立 SHA-256，并保持 Origin MCP 不受影响。

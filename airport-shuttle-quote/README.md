# Airport Shuttle Quote MVP

纯前端机场接送实时报价页面。

## 当前功能
- 接机 / 送机
- 城市 × 机场固定价
- 日期 / 时间附加费
- 乘客数量
- 儿童座椅 / Booster
- 举牌服务
- 首次在线预约示例优惠
- 实时报价拆分
- 手机端响应式布局

## 当前不需要后端
页面所有报价逻辑均运行在浏览器中。

## 后续建议加后端的功能
- 完整地址 → 地图路线距离自动报价
- Google Maps API Key 保护
- 保存订单 / 客户资料
- 后台价格管理
- 优惠码
- 在线支付

价格表和附加费均可直接在 index.html 的 JavaScript 常量中修改。
